# 知识卡片校订说明

本次按“概念严谨，例子日常，少用模板语言”修改网站内容，保留已确认的布局与颜色。

本说明记录第一轮文字校订。之后完成的全面复核、65张卡片修订、15份样题解析修改及12道新增辨析题，以 `全面内容复核报告.md`、`full-content-audit.json` 为当前记录；当前共212题。下文200题、105张概念资料卡等数字是第一轮历史状态。

## 修改范围

- 141 张卡片的概念提要、正文、例子和易错点均重新整理。
- 141 道关联自编判断题的解析随概念更新。200 道题的题干、选项、参考答案和关联编号保持；官方样题没有被改写成生活题。
- 例子使用购物、课表通知、天气、手机相册、邮件、语音消息等；涉及抽象机制时，明确类比的适用范围。
- 删去“把概念放进实际问题”“这一步最容易混淆”等重复句，替换大量“链路、业务、治理”等不必要表达；保留真正需要学习的技术名词。

## 概念与出处

每张卡片展开“来源”后，先显示考试范围依据，再显示概念依据。教材、机构规范、官方技术文档和作者论文分开标注；中文为复习释义，不冒充考试院逐字定义。

105 张卡片列出具体概念资料；另外 36 张主要属于考纲的应用领域、资源支撑或实践能力范围，明确显示“考纲范围说明”，不补造统一定义。例子均标为自写说明。具体章节、链接和卡片映射保存在 `content/concept-sources.txt`，实际采用范围记入 `docs/外部资料采用记录.md`。

例如，RAG 的定义不限定必须用向量数据库；KV Cache 解释为键、值张量，区别于答案缓存；TTFT 与 TPOT 按 token 解释，生活例子中使用“字”时另行说明；AI 系统定义与 AI 研究领域、历史事件分开。

## 使用记录

卡片和题目 ID、本地进度键及格式保持。已有收藏、掌握程度、错题与草稿无需迁移；继续在原浏览器、原文件地址使用即可。

## 验证记录

`docs/网站交互验收.json` 记录答题、收藏、自评、搜索、草稿、备份往返等流程及全部141卡/200题的路由检查。`docs/card-copy-audit.json` 另记录本次文案字段检查、题目原文比较和手机端全部标签及来源区检查。

自动检查能发现内容遗漏、交互失败和页面溢出，不能替代教材阅读或官方评分。原有7道歧义样题仍不自动计对错，操作题仍采用参考提纲与自查。
