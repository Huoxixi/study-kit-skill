# 交互式复习网站

## 设计与范围

已有批准的页面、色彩和操作路径，沿用它们。新网站先提供看得见的设计结果；用户只请求设计时不提前交完整代码。已有授权后完成内容和真实交互，不反复把常规实现选择交回用户。

默认方向是单个学习对象居中、简洁中性背景、一个清楚的主行动色，对错同时用颜色和文字表达。保持长时间阅读所需的字号、行距、对比和空白。不要把某次项目的课程标识、具体色值、卡片数量或布局像素当成所有新项目必须复制的品牌。

若相关设计或文档技能已可用，可按任务读取；本 Skill 不依赖特定插件、部署服务或框架。未经用户要求不增加账号、云同步、付费服务或公开发布。

## 阅读区与固定操作

- 外围应用区域使用可用视口高度，正文区域允许收缩；长内容不能撑走上下张、提交、自评、收藏或来源入口。动态视口和低高度横屏需有明确布局。
- 切卡、切题、收藏、自评、提交时不调用整页回顶或自动滚到解析。解析用明确的“查看解析”入口，由用户主动定位到内部区域。
- 长正文、题目/解析、来源、搜索结果、收藏和资料窗口均有可见的内容上页/下页与位置提示。内容翻页和切换下一张是不同操作，文字和位置应区分。
- 翻页保留适当重叠，避免跨页跳过文字或控件；首尾正确禁用。可以同时保留自然内部滚动，不能把它作为到达某个按钮的唯一方式。
- 标题、关闭、主要操作和翻页按钮不随内部长内容移走。小窗口重新安排布局，不靠截断题干、隐藏选项或删除来源来挤空间。
- 阅读位置按卡片ID与标签、题目ID、收藏分类分别记录；重绘时保存旧DOM对应的键，再恢复新DOM。打开弹窗不应重置仍存在的正文区。会话内阅读位置与持久学习记录分开说明。
- 菜单方向不能越出屏幕；来源和资料宜用有固定关闭/翻页入口的窗口。长列表应显示全部匹配内容，或提供明确且可操作的分页，不能悄悄只留前若干项。

## 真正可用的学习闭环

按交付范围实现并检查：主题/章节筛选；概念/例子/易错点；关联练习；选择、提交、重做与解析；主观草稿、参考提纲和自查；回看原知识及返回原题；收藏、错题/薄弱点；搜索；进度保存与备份导出/导入。

学习检查不预测正式成绩。争议题不计自动对错；主观题自评不伪装成自动评分。统计数量由数据算出，不残留旧题量或科目名。

进度使用稳定的课程键、数据版本和内容ID。升级尽可能兼容旧记录；草稿和作答不能被重新生成的网站抹掉。合并备份要校验身份与结构，按明确规则保留记录，坏文件不能破坏现有状态。任何清空功能有明确范围且不作为普通升级步骤。

默认离线交付时，实际以本地文件方式验证；不要只验证开发服务器。资源、字体、脚本需可离线加载，保存字体和代码许可；原始材料相对链接说明依赖位置。检查用户文本安全渲染，避免将导入数据直接当HTML执行。

## 可选发布

手机通过网址阅读HTML，通常只需响应式网页与适当托管，不必为此改成App。仅在用户要求上线时处理发布；本地改动、打包完成、已上传与公网已验证分别记录。

用户已有服务器或域名时，先查看现有部署文档和可用连接，做只读身份/站点核对，再选最小发布路径。某个受限账号不能操作，不等于不存在其他既有入口；文件存在也不等于凭据有效。区分网络超时、认证失败和权限不足，不把几者混为一谈。

保持现有保存会话和认证配置。不要为脚本兼容而修改原工作区标记或依赖图形客户端关窗时的自动保存；必要的临时会话应隔离、及时清理并先验证。认证不可用时保留可审查的本地候选，不索取或展示秘密，不降低主机校验，不擅自重置密码。

同服已有网站时，使用独立目录、子路径或明确的子域名，先备份配置再作最小变更，检查通过才重载。保留原站业务版本与数据，准备回退；发布后同时核对新入口、原站入口和相对资料链接。不要上传整个课程工作区，也不把密钥、真实学习记录或原项目私有材料放进发布包。

学习记录存在浏览器时，说明换设备不会自动同步，提供可用的导出/导入。多个网站需要互相跳转时，入口应直接可见，窄屏不遮挡原按钮，验证往返后的记录保留。浏览器模拟与真实手机检查分别记录。

## 验收路径

根据交付和变更选择必要检查，不为每次小改重跑完整内容研究。

1. **内容完整**：所有卡片、题目与关联可到达；题干、选项、背景、代码、来源在页面上完整呈现；长内容不会被CSS永久裁掉。
2. **位置稳定**：连续切换长短卡片，记录主面和操作栏边界；收藏、自评、提交和开关弹窗前后检查阅读位置及整页滚动位置。
3. **操作可达**：选取桌面、笔记本常见高度、窄屏、横屏；通过实际可见分页按钮访问选项、自查、回看、来源、备份等。自动化工具可能偷偷滚动后才点击，因此要额外检查控件与阅读区的交集和实际命中，不能只看click成功。
4. **记录与恢复**：用隔离浏览器记录测试收藏、作答、草稿、刷新、备份往返、错误备份、旧版本兼容。不要拿真实用户记录测试清空。
5. **键盘/触摸与边界**：导航焦点、弹窗Esc关闭、输入时不抢快捷键；空筛选、无搜索结果、只剩一项、最后一题、争议题、长标题、长代码和长解析。检查运行错误、意外联网和横向溢出。字体加载和页面缩放后控件仍可到达。

屏幕尺寸是“浏览器可用区域”，不是设备标称分辨率。记录浏览器和实际执行环境；手机模拟、真实设备及软键盘验证分别说明。短窗口阅读分页变多可以接受，整页找按钮和丢失内容不能据此通过。

先完成实现，再一次成批看桌面/手机代表状态，集中修复后做确认；功能失败需要修复并复测，审美微调不无限循环。将通过项、未验证项和仍存在的限制写进交付记录，不把截图美观当成功能或内容正确的证据。
