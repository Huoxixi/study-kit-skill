# 章节主线与知识关联

知识卡是可查阅单元，不能代替有组织的教学。先按科目建立“要回答的问题 → 必要前提 → 机制/推理 → 常见例子 → 练习 → 归纳”的章节顺序，具体顺序服从内容；需要时允许回看前提，不机械套成固定六屏。

每个单元说明为什么在此处出现、依赖什么、学完如何接到下一点。范围映射与来源保留在内容层，不能为了讲故事删去重要边界或大纲子点。复习路线表示阅读位置，不能自动计作掌握；掌握应来自实际练习或明确自评。

默认在知识卡旁用简洁线路显示章节、当前阶段和位置，手机紧凑上置。重要的前提、对比、因果联系才附回看链接；不要让每张卡都挂大量关联，打断教学主线。点击关联再返回，应保留原卡及其阅读位置。

完整网状图放在独立宽敞空间，按章节/机制分组，连线有可追踪的意义，文字、节点与边不相互遮挡。长解读按需打开，主学习页不同时堆放卡片、整图、解释和全部工具。用户只要求旁侧线路时，不擅自增加完整图谱。

未经当前用户明确选择，不把复习改成关卡、房间、角色探索、积分或每日打卡。可视化要说明思路和当前位置；装饰复杂度不等于教学效果。

验收时用一段真实教学链检查：从问题能否自然学到机制、例子是否保持概念、练习是否检验该机制、回看前提后能否返回。编号连续或卡片数量齐全不构成教学连贯的证据。
