# 手机阅读、资料库与按需发布

仅要求手机阅读时先做响应式HTML/网址，不默认加入账户或服务器。用户明确要求朋友使用、个人资料库或云同步时，才扩展为应用容器。已有原生安卓阅读器与网页版分别维护，不把APK支持等同于苹果支持。

## HTML资料库

- 一个导入条目对应一份真实HTML，标题、文件名和打开目标一致；新用户没有导入时为空，并提供明确导入入口。设计截图中的演示文件只能在隔离测试环境，不写进用户账户。
- 独立HTML与依赖相邻PDF、图片、脚本的页面区别说明。容器不能承诺任意HTML的全部外部功能自动可用。
- 如果执行导入HTML的脚本，使用隔离阅读容器，不给它登录页同源权限；仅桥接明确支持的学习存储/下载范围。资料、记录和待同步缓存按账户与文件身份隔离，文件名变化不能串记录。
- 注册方式、字段规则、同步和找回机制服从当前项目，不把某个项目的用户名长度、密码长度、无邀请码或管理员策略写成所有课程默认。
- 更新HTML与应用升级保留稳定ID及学习记录；分享默认只给资料副本，不泄露分享者学习记录，具体分享范围应有说明。并发保存需有冲突处理，不能默默覆盖另一设备。

## 安卓与苹果网页

使用系统文件选择器。微信收到HTML时可先保存到系统“文件”再导入，或用明确实现的资料分享链接；普通网页不能自动读取微信聊天文件，不宣称实现微信文件选择/登录。苹果可按实际Safari版本提供添加主屏幕的指引，仍是网页应用，不是原生安装包。

检查窄屏、横屏、动态视口、安全区、弹窗和输入焦点。表单文字保持手机可读字号，保留浏览器缩放；输入键盘、地址栏收缩与主屏幕模式需要真机验证。功能不能依赖鼠标悬停，抽屉关闭后再打开其他弹窗，关闭入口始终可达。

分别记录Chrome/Chromium移动视口、WebKit触屏视口、安卓模拟器和物理设备的证据。桌面WebKit即使使用iPhone名称/UA也不是iOS真机。至少验证注册/登录（如有）、导入、打开、切卡、学习记录刷新恢复、备份导出/恢复、手机导航；原HTML的能力单独核对。仅有manifest或截图不能称全部兼容。

## 发布与开源

用户授权上线后，先核对真实连接身份、原站版本与配置；先备份、预检查、准备回退，再上传白名单文件。保留已有站点、接口和用户数据。密钥能登录受限运维账号不代表拥有root权限；不要借原项目发布器越过其允许范围，也不改用户保存的认证来迁就脚本。

公网检查应覆盖HTTPS、注册/登录、手机核心流程和原站入口。生产验收用可识别的临时账号与合成资料，避免以真实用户记录测试清空。故障、未上传、已上传、已启动、已公网验证分别陈述。

开源采用显式文件清单，排除密钥、私有数据、服务器专用配置和原始课程附件。只发布有分发依据的代码与素材，用户粘贴的第三方组件不能仅因依赖用MIT就整体标MIT；保留实际许可、改动与来源。通用Skill可先独立开源，课程材料、应用与发布记录各按各自范围审阅。
