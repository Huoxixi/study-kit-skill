# 复习工坊 · 安卓版

将复习资料工坊生成的独立 HTML 导入手机，离线看卡片、做题和保留学习记录。支持 Android 8.0 及以上，手机优先；无需账号或服务器，应用不申请联网和全盘存储权限。

## 安装与使用

1. 把正式版 APK 传到手机，保存到手机后点开安装。按系统提示允许这次使用的文件管理器或传输应用安装 APK。
2. 打开“复习工坊”，可先在“课程管理”中新建课程，再点“导入 HTML”。文件选择器支持多选 `.html` / `.htm`，批量导入后也能一并归类。首次可用内置示例体验。
3. 导入后文件复制到应用内部，删除原始下载文件不影响阅读。每份资料分别保存收藏、答题、草稿等网页学习记录。
4. 资料库支持课程筛选、文件搜索、最近学习/最近导入/名称排序与置顶。每份资料可重命名、移动课程分类、更新或删除。
5. 相同标题的不同 HTML 独立保存；同一课程内完全相同的内容会提示或在批量导入时去重。“管理 → 更新 HTML”指定更新对象，保留自定名称和进度。不要用重新导入代替给旧资料分类。
6. 学习页顶部“资料库”返回列表；“备份”导出 HTML、学习记录、自定名称、课程分类、原文件名及置顶状态。在资料库选择该备份可恢复。
7. 网页原有的进度 JSON 导入、导出也可使用。只有进度的 JSON 应通过网页自己的进度导入按钮恢复。

1.1.0 可以覆盖安装 1.0.0，沿用原签名、资料编号和存储来源。旧资料在“未分类”中，归类不重置进度。移除课程分类只将资料移到“未分类”，不会删除内容。

支持独立 HTML、HTM、常见网页片段，UTF-8、带 BOM 的 UTF-16，以及正确声明 GBK 等字符集的网页。单个 HTML 最大 20 MB。卡片、题目、脚本、样式、字体和图片应包含在文件中，交互由 HTML 自身提供；旁边的目录与其他文件不会自动导入。外部来源链接由用户确认后交给浏览器打开。卸载应用会清除应用内资料，卸载前请导出备份。

## 源码与构建

`src/` 是原生 Java 应用，`assets/reader-bootstrap.js` 负责把网页生成的本地下载接到系统保存窗口。正式包非 debuggable，代码显式调用网页调试关闭 API；调试系统的例外见验收记录。不给导入页面暴露通用设备操作接口。

本地构建使用微软 OpenJDK 17、Android SDK Platform 35、Build Tools 35.0.0 中的 AAPT2、D8、zipalign 和 apksigner，无 Gradle/Maven 运行依赖。构建工具放在 `.toolchain/`，没有打包进 APK。固定版本、官方下载地址和校验值见 `tools/build-packages.json`；来源见项目 `docs/外部资料采用记录.md`。

在项目根目录用 PowerShell 7 运行：

```powershell
./android-app/tools/bootstrap.ps1
./android-app/tools/build-local.ps1
```

首次构建需要联网下载官方工具；阅读应用本身离线运行。`bootstrap.ps1 -VerifyOnly` 只检查已有归档的大小与校验值。公开源码不提供发行私钥：首次本地构建会生成自己的签名，不能覆盖安装本项目的正式 APK；使用正式版的用户从版本下载页安装升级。

正式包按 manifest 版本号生成，目前为 `dist/StudyKit-Reader-1.1.0.apk`；`-Qa` 生成仅用于验证的调试包。构建包装脚本临时映射英文盘符以兼容官方打包工具对中文路径的限制，结束后撤销映射。

`signing/` 保存本地发行签名和密码，不分发、不提交。今后覆盖升级需要继续使用这份签名；请妥善备份该目录。版本更新还需增加 manifest 中的版本号。

1.0.0 历史验收保留在 `docs/安卓APP验收.md`；多课程版以 `docs/安卓APP多课程升级验收.md` 与 `android-app/qa/*1.1.0.json` 为准；不把编译成功等同于真机验证。

公开仓库保留的 1.1.0 验收 JSON 与最终截图位于 `docs/qa/`，均来自实际测试记录；本地运行测试生成的 `android-app/qa/` 仍被忽略。历史升级测试需要先准备 1.0.0 安装与旧进度，测试脚本固定使用 `emulator-5580`，不会自动适配任意手机。
